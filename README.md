# Nash Crawford — Personal Website

Portfolio site for Nash Crawford, graduate assistant coach and social media manager for Howard Payne University men's basketball.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The website (all styles included in the file) |
| `404.html` | Page shown when someone visits a link that doesn't exist |
| `favicon.svg` | The small "NC" icon shown in the browser tab |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is |

## Publish on GitHub Pages

1. Create a new public repository on GitHub. Naming it `<your-username>.github.io` gives you the address `https://<your-username>.github.io`; any other name gives `https://<your-username>.github.io/<repo-name>`.
2. Upload all of these files to the repository (on GitHub: **Add file → Upload files**, then commit). Make sure `.nojekyll` is included; it's a hidden file, so you may need to show hidden files on your computer to see it.
3. Go to **Settings → Pages**. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose the `main` branch and the `/ (root)` folder, and click **Save**.
4. Wait a minute or two, then refresh the Pages settings to see your live link.

## Editing

Open `index.html` in any text editor, change the text, and upload the updated file. The site updates automatically after each commit.

## Custom domain (optional)

If you buy a domain, add it under **Settings → Pages → Custom domain** and follow GitHub's DNS instructions.
